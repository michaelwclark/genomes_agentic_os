# 34 Documentation And Help Guide For 08 Losmon Replacement Validation

Create an operator-facing guide for feature 08 that explains how to generate
the LOSMon replacement validation package and interpret its read-only evidence.

## Acceptance

- Document `agentic-os losmon validate --root <root> --repo <repo>`.
- Explain generated project state, workflows, automation, run logs, and
  comparison artifact.
- State that validation is read-only and does not replace LOSMon by itself.
- Preserve explicit comparison gaps where LOSMon remains better or required.
