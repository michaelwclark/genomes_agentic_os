# Spec

Add durable future idea intake so ideas do not remain only in chat.

## Command

```bash
agentic-os plan capture --root ~/agentic_os --title "..." --summary "..."
```

## Acceptance

- OS product ideas are written under `shared_factory/05-knowledge/plans/future-ideas/`.
- Domain ideas append to `<domain>/01-inbox/raw-ideas.md`.
- Customer or project ideas append to the project status file.
- Plan capture is additive and preserves installed root validation.
