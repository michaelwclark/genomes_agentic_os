# 02 Routing And Context Builder

Source plan: `PLANS/02-routing-and-context-builder.md`

The feature adds deterministic routing and context-packet commands:

- `agentic-os route "<request>"`
- `agentic-os context build`
- `agentic-os here route`
- `agentic-os here context build`

The output includes domain, lane, object type, target path, source files to load, approval risks, known gaps, and a handoff prompt.
