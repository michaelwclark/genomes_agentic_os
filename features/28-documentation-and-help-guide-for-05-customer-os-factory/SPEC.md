# 28 Documentation And Help Guide For 05 Customer Os Factory

Create an operator-facing guide for feature 05 that explains how to generate,
update, and validate customer-specific Agentic OS roots from customer profile
YAML.

## Acceptance

- Document `agentic-os customer init`, `customer update`, and
  `customer validate`.
- Explain the source package versus generated customer runtime boundary.
- Explain approved domains, workflows, automations, profile schema, and example
  profile locations.
- Explain additive update behavior and private source-owner filtering.
- Explain `core_errors` and `profile_warnings`.
