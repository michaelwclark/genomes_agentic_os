# 01 Project Create And Active Work

Source plan: `PLANS/01-project-create-and-active-work.md`

The feature adds `agentic-os project create <domain> <project>` so installed OS roots can hold durable project state under `<domain>/02-projects/<project>/` instead of depending on ad hoc working directory context.

Acceptance requires project files, active-work indexing, project index rows, source-map references, idempotency, validation after creation, invalid-name coverage, and `lenders` to `los` alias behavior.
