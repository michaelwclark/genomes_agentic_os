# Spec

Promote customer automation and control-plane playbooks into first-class installed Agentic OS runtime assets.

## Scope

- Add command prompts for client automation briefs, control-plane bootstrap, and context audits.
- Add matching skills for repeatable operator use.
- Require the installed runtime to contain those command and skill files.
- Verify customer-facing playbook material stays generic and approval-gated.

## Out Of Scope

- No Notion writes for customer installs.
- No autonomous customer workers.
- No private database IDs or customer-specific examples.
