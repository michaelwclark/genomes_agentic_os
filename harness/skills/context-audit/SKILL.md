# Context Audit

Use this skill to reduce context loading risk in a room, workflow, automation, or customer OS.

## Workflow

1. Identify the task boundary.
2. Separate read-first, read-when-needed, and do-not-load files.
3. Check `shared_factory/05-knowledge/references/source-priority.md`.
4. Check whether tools and skills are routed by task or stage.
5. Recommend moves into references, examples, templates, archive, or source maps.

## Done

- Findings are severity-ranked.
- The agent can load less context and still act correctly.
- Approval risks and stop conditions are explicit.
