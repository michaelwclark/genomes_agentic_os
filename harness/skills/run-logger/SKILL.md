# Run Logger

Use when ending a non-trivial OS session.

## Workflow

1. Create or update the run log.
2. Record route, input, sources loaded, actions taken, validation, artifacts, final status, and next action.
3. Update project status or workflow progress.
4. Promote durable lessons to context, routing rules, templates, or memory policy.

## Completion Standard

Another agent should understand what happened and what to do next without reading the chat.
