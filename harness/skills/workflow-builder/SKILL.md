# Workflow Builder

Use when creating or completing a workflow folder.

## Workflow

1. Route the request to domain and lane.
2. Create the workflow scaffold if needed.
3. Complete outcome brief, alignment questions, PRD, implementation plan, context pack, approval rules, output contract, and runbook.
4. Add examples when the workflow needs consistent output.
5. Update the related project or active-work file.

## Completion Standard

A fresh agent should be able to run the workflow without relying on chat history.
