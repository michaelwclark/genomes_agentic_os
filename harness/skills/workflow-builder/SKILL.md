# Workflow Builder

Use when creating or completing a workflow folder.

## Workflow

1. Route the request to domain and lane.
2. Read `harness/rules/os-authoring-rules.md`.
3. Create the workflow scaffold if needed.
4. Complete outcome brief, alignment questions, PRD, implementation plan, context pack, approval rules, output contract, and runbook.
5. Add examples when the workflow needs consistent output.
6. Add a matching slash command and skill when the workflow should be directly invoked.
7. Update registries, readable `TOOLS.md`, the related project, active-work, and worklog.

## Completion Standard

A fresh agent should be able to run the workflow without relying on chat history.
