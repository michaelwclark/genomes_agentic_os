# Learning Promoter

Use when a run reveals durable knowledge that should improve future OS behavior.

## Workflow

1. Read the run log and changed artifacts.
2. Decide whether the lesson belongs in context, references, source map, routing rules, workflow template, automation permissions, examples, or metrics.
3. Apply the smallest durable update.
4. Link back to the evidence run.

## Guardrails

Do not promote one-off noise into global policy.
