# OS Doctor

Use when validating, cleaning, or repairing the installed OS.

## Workflow

1. Run structure validation.
2. Inspect stale active work.
3. Find missing required files and sections.
4. Find automations without permissions, tests, or logs.
5. Find run logs without final state.
6. Propose safe repairs.
7. Archive inactive work only with explicit approval.

## Output Contract

Report findings by severity and include exact paths.
