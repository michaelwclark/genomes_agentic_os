# Good Program Contract

Give operators a navigable front door: purpose, outcomes, workflow map,
invocation choices, shared policy/configuration, failure recovery, receipts,
ownership, metrics, and compatibility/retirement map. Each workflow should have
its own page and visual flow; avoid one dense wall of prose.
