# Tools

- `$auto-dev-health`: delivered-item facade and strict final receipt.
- `$os-cleaner`: general cleanup facade.
- `agentic-os project worktree cleanup-closed`: dry-run/guarded registry and
  Git-worktree reconciliation. Physical removal requires exact `--domain`,
  `--project`, and `--worktree` selectors plus packet-local
  `--health-preflight` and `--runtime-receipt` files.
- `agentic-os project work-item set`: filesystem packet lane transition.
- `agentic-os work set` and `work active-now`: canonical state and active
  projection reconciliation.
- `agentic-os validate`: structural readback.
