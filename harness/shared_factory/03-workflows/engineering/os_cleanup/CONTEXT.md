# Context

The durable packet and canonical work registry are preserved truth. Worktrees
and uniquely item-owned local runtimes are reconstructable resources. A typed
provider-read Merge receipt must bind the reviewed source head, provider, PR
reference, and exact merge revision before deletion; Health reuses that
authority exactly. Physical worktree removal also requires a clean Git status;
dirty-change preservation is a separate operator workflow, not a Health
exception.
