# OS cleanup

This is the canonical receipt-first policy for Agentic OS worktree, target-local
runtime, registry, active-index, and finished-packet cleanup. `$os-cleaner` is
the general invocation mirror; `$auto-dev-health` is its delivered-item facade.
Health is manual and exact-item scoped. This workflow never schedules physical
cleanup or performs a host-wide/all-resource Docker/OrbStack operation.
