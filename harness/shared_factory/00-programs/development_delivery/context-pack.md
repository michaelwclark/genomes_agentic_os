the active work item, its task `state.json`, the project domain investigation
results relevant to the change, and the current worktree diff. Add production
or pre-production read-only evidence only when the grooming check identifies a
data-dependent decision. Store source snapshots as task receipts; do not copy
entire repositories or generic OS documentation into the prompt.
