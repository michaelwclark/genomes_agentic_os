# Documentation contract

The durable human surface is this program folder plus one `workflow.md` per
workflow. The machine surface is `components.yml`, the profile schema, and one
`workflow.yml` per workflow. Run receipts belong with the task work item, not
in the program documentation. Inline code comments should explain non-obvious
invariants and failure behavior, not restate syntax. Promote a learning only
when it changes future implementation decisions.
