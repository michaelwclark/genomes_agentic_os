# Agent Entry Point: Spec Engine

This OSProgram owns the canonical idea-to-built Spec lifecycle. The directory
name `spec_grooming` is retained as a compatibility path; the program identity
is `spec_engine`.

## Startup Loop

1. Read `ROUTER.md`, `CONTEXT.md`, `RULES.md`, `TOOLS.md`, and `program.md`.
2. Read `components.yml` before editing linked commands, skills, templates,
   examples, registries, docs, or projection rules.
3. Resolve the layered Spec Engine policy before choosing a lifecycle authority,
   storage adapter, or tracker destination.
4. Preserve raw user intent before polishing any spec.
