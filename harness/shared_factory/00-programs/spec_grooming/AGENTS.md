# Agent Entry Point: spec_grooming

This OSProgram owns the universal spec grooming contract.

## Startup Loop

1. Read `ROUTER.md`, `CONTEXT.md`, `RULES.md`, `TOOLS.md`, and `program.md`.
2. Read `components.yml` before editing linked commands, skills, templates,
   examples, registries, docs, or projection rules.
3. Keep filesystem packets as source of truth. Linear, Jira, and Notion are
   projections unless a narrower project config explicitly says otherwise.
4. Preserve raw user intent before polishing any spec.
