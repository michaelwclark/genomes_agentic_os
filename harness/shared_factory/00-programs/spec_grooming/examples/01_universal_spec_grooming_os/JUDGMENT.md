# Judgment: Universal Spec Grooming OS

## Decision

`create_under_existing`

## Reasoning

Existing domain groomers remain useful, but none owns the universal
intent-preserving wrapper. The new program binds the reusable contract while
delegating domain-specific execution to existing adapters.

## Projection Notes

Tracker and Notion output must use sanitized summaries. Local packet paths stay
in internal receipts unless the target audience has access to them.
