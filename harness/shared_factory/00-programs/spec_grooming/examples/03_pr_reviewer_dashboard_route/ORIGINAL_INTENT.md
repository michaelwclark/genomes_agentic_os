# Original Intent: PR Reviewer Dashboard Route

## Raw Capture

If someone asks for a PR review dashboard, the groomer should not immediately
create a new dashboard. It should check existing PR health, team PR sync, and
active PR board surfaces first.

## Intent Anchors

- Treat dashboard requests as likely overlaps with existing operator surfaces.
- Prefer extending the current owner if one exists.
- Keep output source-backed and avoid duplicating attention surfaces.
