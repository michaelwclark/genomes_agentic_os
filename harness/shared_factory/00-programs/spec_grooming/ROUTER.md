# Router: Spec Engine

Route every idea, ticket, backlog item, feature request, bug, configuration
change, or software spec through this program before changing component
internals. `spec_grooming` remains a legacy route to this program.

| Request | Route |
| --- | --- |
| Add, inspect, transition, sync, or diagnose a spec | `harness/skills/spec-engine/SKILL.md` |
| Rough idea, feature concept, bug, config change, or future work | `harness/commands/os-add-spec.md` |
| Deep grooming request | `harness/commands/os-groom-spec.md` compatibility adapter |
| Packet shape or original-intent requirements | `templates/` |
| Example quality or holdout coverage | `examples/` |
| Registry or harness visibility change | `components.yml` and the linked registries |
| LOS or Jira-primary work | Use the project policy and Jira adapter; delegate detailed team grooming to `$jira-product-orchestrator` when configured |
