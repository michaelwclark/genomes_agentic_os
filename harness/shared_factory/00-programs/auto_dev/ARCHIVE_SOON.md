# Archive Soon: Auto-Dev Overlap Ledger

This is a migration ledger, not permission to delete working capabilities.
Every retirement needs parity evidence, a compatibility breadcrumb, registry
and router cleanup, retained receipts, rollback instructions, and a verified
replacement manual entrypoint.

## Archive candidates after parity

1. Duplicate state machines or quality ledgers inside LOS workon/queue helpers.
2. Direct Jira/Linear/Notion formatting prompts embedded in producer skills.
3. Copied DEV_STANDARDS, QA, gitflow, artifact, or investigation rules outside
   their policy planes.
4. PR repair fleet/watch workflows that do more than trigger or observe the
   canonical review/repair stage.
5. Ad hoc investigation playbooks that duplicate Detective phases instead of
   declaring a source adapter.
6. Root and installed-only Auto-Dev program copies once source install parity is
   verified.

## Keep as reusable adapters

- Spec Engine for intent, grooming, and work lifecycle.
- Project Domain Intelligence and Genome's Brain for bounded knowledge retrieval.
- LOS tenant-data, config, rules, version registry, and env-shell transports.
- Kanga repo/release/environment adapters.
- Finishing-review, quiet watcher, CI, deployment, notification, and provider
  tools that expose one bounded capability without a second workflow policy.
- Specialized status/release-note/report engines after they consume the common
  artifact renderer.

## Migration checklist per item

- [ ] Replacement command/skill works manually from a fresh chat.
- [ ] Implicit router selects the replacement for equivalent language.
- [ ] Root/domain/project policy parity is proven by fixtures and a live sample.
- [ ] Existing active run can resume or has an explicit migration receipt.
- [ ] Registries, `TOOLS.md`, dashboards, docs, schedules, and Notion links point
  to the replacement.
- [ ] Old surface contains a breadcrumb and rollback note or is archived with
  history intact.
- [ ] One observation window shows no remaining unique invocation.
