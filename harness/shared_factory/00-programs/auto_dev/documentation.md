# Documentation Contract

The source-of-truth documentation is this program folder, one complete
`workflow.md` beside each machine `workflow.yml`, the policy-plane READMEs, and
the command/skill adapters. Genome's Notion is a rich projection built from
these verified surfaces.

The Notion program home must remain skimmable and visual. Each workflow gets a
child page, and complex topics get child pages beneath it. Multi-step workflows
need a flowchart image. Use callouts, tables, toggles, columns, and concise
sections rather than a dense Markdown wall. Read back every created page and
verify parent, title, hierarchy, and rendered content.
