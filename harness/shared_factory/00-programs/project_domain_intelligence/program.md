# OSProgram: project_domain_intelligence

## Status

- Status: active

## Purpose

Own portable, evidence-backed project-domain intelligence: discovery, article
production policy, refresh, retrieval, validation, and retirement. The program
extends the existing `project-domain-architecture-analysis` workflow and
`project-domain-analysis` toolkit rather than creating another analyzer.

## Owner

- Shared contract owner: `shared_factory`.
- Project configuration and article instances: the owning project domain.

## Scope

- Commands and cross-harness skill adapters.
- The legacy workflow/toolkit compatibility path.
- Read-only refresh receipts and operator attention projection.
- Retrieval contracts consumed by grooming, auto-dev, implementation planning,
  PR review, and documentation upkeep.

## Explicit boundaries

- Topic-focused articles are not one article per source folder.
- Generated articles never outrank current source evidence.
- Scheduled refreshes do not modify articles.
