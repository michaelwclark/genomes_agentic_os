# Rules: Project Domain Intelligence

- Keep source evidence authoritative; do not copy large source blocks into articles.
- Link the legacy workflow and toolkit instead of duplicating their behavior.
- A scheduled refresh is observe-only: it may inspect source and write one
  receipt, but must not replace an article, change a project, or call an
  external service.
- Article replacement requires an explicit human-approved run and preserves
  contradictory evidence.
- Keep secrets, customer data, and local-only paths out of generated articles
  and external projections.
