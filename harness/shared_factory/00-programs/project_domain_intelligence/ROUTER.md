# Router: Project Domain Intelligence

Use this program for project-domain investigation, context retrieval, article
freshness, or refresh requests.

- Investigate or retrieve: load `context-pack.md`, then `components.yml`.
- Change policy or a linked surface: load `crud.md` and `tests.md`.
- Run or diagnose refresh: load `runbook.md` and the latest receipt.
- Retire an instance: load `RULES.md`, `components.yml`, and `runbook.md`.
