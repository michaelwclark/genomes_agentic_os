# Shared Programs

Each child is a reusable OSProgram: a named capability composed from skills,
commands, workflows, documentation, validation, and context contracts.

| Program | Purpose |
| --- | --- |
| [`development_delivery/`](development_delivery/) | Run one or many tracker-backed programming tasks through isolated implementation, testing/repair, release, deployment, and cleanup. |
| [`spec_grooming/`](spec_grooming/) | Turn rough software ideas into implementation-ready canonical Specs while preserving intent and discovering existing capability. |

Programs are not ad-hoc working directories. A program must document ownership,
components, CRUD behavior, context, runbook, tests, and work history.
