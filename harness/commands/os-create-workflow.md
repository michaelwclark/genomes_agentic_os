# OS Create Workflow

Use when a repeatable process needs judgment, context assembly, validation, or approval gates.

## Procedure

1. Route the request first.
2. Run `agentic-os workflow create <domain> <lane> <workflow> --root ~/agentic_os`.
3. Fill `outcome-brief.md`.
4. Fill `alignment-questions.md`.
5. Fill `prd.md`.
6. Fill `implementation-plan.md`.
7. Fill `context-pack.md`.
8. Fill `approval-rules.md`.
9. Update active work or the related project.

## Stop Condition

Do not dispatch implementation work until the outcome, scope, context, and approval gates are clear enough for a fresh agent to continue.
