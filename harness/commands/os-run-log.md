# OS Run Log

Use when a session did non-trivial work or changed OS state.

## Procedure

1. Create or find the run log.
2. Record input and route.
3. Record sources loaded.
4. Record actions taken.
5. Record validation performed.
6. Link artifacts.
7. Set final status.
8. Add next action and owner.
9. Promote durable learning to context, source maps, routing rules, templates, or memory policy.
