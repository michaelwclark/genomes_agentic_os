# OS Route

Use when a request needs to be placed inside the installed Agentic OS.

## Procedure

1. Read root `ROUTER.md`.
2. Choose the domain.
3. Read `<domain>/ROUTER.md`, `CONTEXT.md`, and `REFERENCES.md`.
4. Check `<domain>/00-control-plane/active-work.md`.
5. Decide whether the request belongs in inbox, project, workflow, automation, run, knowledge, metrics, or archive.
6. Record the routing decision in the relevant triage, active-work, or run-log file.
