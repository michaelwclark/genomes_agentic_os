# `/auto-dev-pr-create`

Resolve the effective project PR target matrix and create or reuse only the
missing pull requests. Use `$auto-dev-pr-create`; `--apply` authorizes computed
branch/PR writes only. Record the stable Development Delivery compatibility
receipt with `develop stage --stage release_propagation`; Auto-Dev projects it
as `pr_create`.

Compatibility aliases: `/gitflow-pr-create`, `/auto-dev-release-propagation`,
`auto-dev propagate`, and `auto-dev release-propagation`.
