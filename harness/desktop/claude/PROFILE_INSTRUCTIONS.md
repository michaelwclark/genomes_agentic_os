# Agentic OS profile instructions for Claude Desktop

For every request concerning Agentic OS, its domains, projects, workflows,
automations, run logs, skills, tools, routing, context/memory, control plane,
or related repositories, load and follow the enabled
`agentic-os-operating-contract` skill before replying, selecting tools, or
changing files. This applies even when the request sounds like a general
conversation. If the skill is unavailable or disabled, state that clearly and
ask for it to be enabled instead of claiming Agentic OS compliance.

For unrelated requests, use normal Claude behavior.
