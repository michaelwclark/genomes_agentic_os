# Configuration Examples

Publishable example configuration for source-package development and installs.
Real host, project, credential, and workspace values belong in the installed OS
or user environment, never in this directory.

| File | Purpose |
| --- | --- |
| `example.os.yml` | Minimal OS identity and source configuration. |
| `example.projects.yml` | Example project registry entries. |
| `hosts.example.yml` | Neutral multi-host connection and routing shape. |
