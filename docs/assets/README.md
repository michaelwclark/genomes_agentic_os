# Documentation Assets

Images in this folder support the tutorials and architecture guides. SVG is the
editable source when both SVG and PNG variants exist; PNG is the broadly
renderable companion.

| Asset family | Used for |
| --- | --- |
| `beacon-campaign-agents-map.*` | Campaign agent and workspace map. |
| `context-stitching-flow.*` | Context assembly flow. |
| `jennifer-marketing-agents-os-map.*` | Nontechnical marketing campaign example. |
