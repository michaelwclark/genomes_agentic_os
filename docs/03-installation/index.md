# Installation

This directory documents source-package preflight checks for installing Genome's Agentic OS.

- Run `agentic-os validate-source --source <repo>` before install or sync to verify required Codex config sources are present.
- Run `agentic-os validate --root <generated-os>` after generating an install to verify the installed tree without mutating it.

The current install surface is also documented in `docs/10-cli-and-install/README.md`.
