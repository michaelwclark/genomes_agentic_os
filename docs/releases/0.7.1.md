# Genomes Agentic OS 0.7.1

Version 0.7.1 is the post-Rubicon patch release for safer Auto-Dev handoffs,
bounded validation, exact-head review evidence, and lifecycle-gated cleanup.

## Release highlights

- Auto-Dev carries a verified PR-Create escalation through Review, QA,
  Finalize, production validation, and Merge without losing its Develop
  authority.
- Mixed executor handoffs retain an honest partial portfolio result while
  recoverable work remains pending.
- Opposing-model review requests and receipts use the same deterministic run
  identity, preserve structured blocking and advisory findings, and accept an
  advisory `OPEN` to `VERIFIED` transition only for matching explicit
  non-blocking evidence.
- Same-head advisory recovery is bound to the immutable reviewer response and
  canonical findings digest, while policy-allowed reviewer unavailability
  follows the routed `continue_with_receipt` outcome.
- The quiet PR watcher gives exact-head downstream checks two settled polls to
  appear, then rejects required labels that no emitted check run owns.
- Root validation has explicit wall-clock and no-progress bounds, observable
  progress, cancellation, and focused fallback scopes.
- Compose pressure teardown is a report-first, exact-evidence workflow; its
  separate executor revalidates the immutable proposal and retains volumes.
- External worktree cleanup remains gated by exact project registration,
  provider merge state, reviewed revision, clean state, and runtime cleanup.

## Release and installation

Create the immutable `v0.7.1` tag only from the merged, exact-head release
commit after all protected checks, Review Self, Finalize, and production-release
validation pass. Install only the published wheel and digest-pinned release
assets whose provider readback matches that tag. Preserve the v0.7.0 runtime as
the verified rollback target until post-install automation sanity checks pass.
