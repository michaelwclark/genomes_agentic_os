# Genomes Agentic OS 0.7.1

Version 0.7.1 is a patch release for Auto-Dev recovery and host-health safety.

## Compose pressure safety

- Host diagnostics now require lifecycle evidence before a guarded Compose
  pressure teardown can act on unhealthy local resources.

## Health cleanup safety

- Health can remove an external Git worktree only when the exact path is
  represented by a project-owned registration symlink and all existing typed
  provider, revision, branch, clean-checkout, runtime, and preflight gates
  have passed.
- Unregistered or arbitrary external paths remain rejected.

## Mixed portfolio recovery

- A portfolio retains a `partial` rollup when an exhausted executor handoff
  coexists with another recoverable task.
- Single and all-worktree-ready handoffs retain their `pending` disposition.

## Release integrity

- The patch synchronizes the Python package, Fabric manifest, Helm chart, and
  both Fabric service package versions at 0.7.1.
- The immutable `v0.7.1` tag and GitHub Release are created only after this
  reviewed release change passes required checks on `main`.
