# Genomes Agentic OS 0.5.5

Version 0.5.5 closes the final host-runtime gap in the personal fallback alert
path. The v0.5.4 watchdog correctly activated bigmac's local queue and reached
the canonical notifier, but launchd resolved its env-based Python shebang to a
bare system interpreter without the notifier's YAML dependency.

Execution Fabric notification calls now prefer the explicitly configured
Agentic OS or worker Python environment and fall back to the legacy executable
path only when no governed runtime is available. The personal-client runtime
already provides this released Python path, so the correction requires no new
host-local dependency or duplicated notifier.

The topology and authority model remain unchanged: genomesbox is primary;
bigmac owns the two-wide PR worker, desktop alarm delivery, and a separate
latched SQLite fallback; no shared-ledger promotion or automatic failback is
enabled.
