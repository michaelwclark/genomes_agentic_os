# Genomes Agentic OS 0.5.0

This release adds a practical continuity mode for a personal two-host Agentic
OS installation: genomesbox remains the shared primary, while bigmac can keep
its own automations moving locally during a genomesbox outage.

## Genomesbox-primary personal fallback

- `remote_with_local_fallback` uses the authenticated genomesbox control plane
  during normal operation.
- A separate bigmac watchdog probes readiness once per minute and activates
  only after three consecutive failures by default.
- Activation latches bigmac onto its existing durable local SQLite queue. The
  latch survives process and host restarts.
- Work already admitted by genomesbox stays in its PostgreSQL ledger and waits
  for recovery. The fallback never guesses whether an uncertain remote submit
  committed and then duplicates it locally.
- Primary recovery is reported, but never triggers automatic failback. The
  explicit failback command first proves genomesbox readiness.

This mode favors understandable personal continuity over consensus-grade high
availability. It does not claim automatic shared-ledger takeover, zero data
loss, or network-partition fencing.

## Operator commands

```bash
agentic-os runtime fallback status --json
agentic-os runtime fallback probe --apply --json
agentic-os runtime fallback activate --reason maintenance --apply --json
agentic-os runtime fallback failback --apply --json
```

The macOS deployment assets can activate only the lightweight watchdog:

```bash
activate-macos.sh --apply --personal-fallback
```

The watchdog uses the canonical `runtime.execution_fabric.health` alert route,
so outages and recovery state flow through Agentic OS and desktop notification
instead of becoming another private monitoring island.

## Configuration

The single root-level `harness/config/execution-fabric.yml` remains the queue
policy owner. Personal fallback adds only discoverable transport policy:

```yaml
transport:
  mode: remote_with_local_fallback
  control_plane_url: http://100.64.0.2:3180
  fallback:
    failure_threshold: 3
    state_path: harness/shared_factory/00-control-plane/execution-fabric-fallback.json
```

The state file is mutable host-local runtime state, not configuration and not a
secret. Host identities, routing, and alert destinations remain in their
existing canonical registries.

## Upgrade

Install the 0.5.0 assets on both hosts, configure genomesbox as the shared
primary, configure bigmac with the fallback transport and scoped remote
credentials, then activate the bigmac personal-fallback watchdog. Keep the
full witness, replicated standby, promotion, and failback stack inactive unless
you later choose to adopt consensus-grade HA.
