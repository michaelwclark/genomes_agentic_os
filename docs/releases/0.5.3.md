# Genomes Agentic OS 0.5.3

Version 0.5.3 completes the activation-tested personal fallback contract from
v0.5.2. A live genomesbox-offline drill reached bigmac's latched SQLite queue
and exposed that route authorization classes were being written directly into
the run queue's separate approval-state field.

The runtime now performs an explicit, deterministic translation:

- `not_required` routes materialize as `not_required`;
- closed `policy_gated` routes materialize as `approved` after validation;
- `explicit` routes remain `required` unless the local operator invokes the
  mutating `--apply` submission path, which materializes them as `approved`.

This keeps the safety boundary intact while allowing already-authorized local
work to continue on bigmac during a sustained genomesbox outage. The topology
is unchanged: genomesbox is primary, bigmac never promotes the shared ledger,
fallback remains latched, and failback remains a manual readiness-gated action.
