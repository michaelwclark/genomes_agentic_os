# Genomes Agentic OS 0.5.4

Version 0.5.4 completes the automatic alert path for the personal
genomesbox-primary topology. A live v0.5.3 outage drill proved that bigmac
latched to its local SQLite queue after three failures, but the watchdog used
`jq -e` to read `primary_ready`. Because jq intentionally returns exit status
one for the JSON value `false`, the shell exited before sending the critical
desktop notification.

The watchdog now reads the required boolean without conflating its value with
command success. An executable deployment regression proves the exact outage
transition invokes `agentic-os-notify` with critical severity and the stable
fallback dedupe key.

The operating topology is unchanged: genomesbox owns the shared primary;
bigmac owns its independent local fallback queue, two-wide Team PR worker, and
desktop alarm delivery; shared-ledger promotion is disabled; recovery stays
latched until explicit readiness-gated failback.
