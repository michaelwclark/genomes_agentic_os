# Genomes Agentic OS 0.4.2

This patch release hardens installation, recovery, and monitoring for the
unified Execution Fabric introduced in 0.4.0.

## Corrections

- Separate immutable package installation from explicit, preflight-gated
  service activation. Repeated activation is idempotent, and host workers use
  the packaged Python entrypoint by default.
- Preserve macOS paths containing spaces across every Docker Compose recovery
  command and use one target-specific PostgreSQL replication-slot contract.
- Prove PostgreSQL backups through a disposable restore and mount the scoped
  datastore credentials required by control-plane health checks.
- Install concrete CloudWatch alarms for witness ECS tasks, ALB target and 5xx
  health, and DynamoDB throttles and system errors. SNS delivery remains
  optional and operator-controlled.
- Keep the Python package, runtime, Node services, Helm chart, lockfiles, and
  release manifest on one canonical `0.4.2` version.

## Upgrade

Use the digest-pinned images and portable bundles published with the GitHub
release. Installation remains inert until the operator provisions runtime
configuration and secrets and explicitly runs the matching activator.
Automatic promotion must remain disabled until AWS witness alarms, backup
restore validation, artifact replication, and promotion/failback drills have
provider readback.
