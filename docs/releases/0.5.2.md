# Genomes Agentic OS 0.5.2

Version 0.5.2 is the activation-tested personal-primary release. It preserves
the v0.5.1 queue, worker, monitoring, alarm, and personal-fallback contracts
while repairing fresh MinIO bootstrap against the published client image.

The observer policy is now rendered with shell built-ins only. A live
genomesbox activation exposed that the immutable MinIO client image does not
include `sed`; v0.5.1 therefore stopped after creating the bucket and observer
user. The new deployment-contract guard prevents that dependency from
returning.

The Compose definitions also preserve the control-plane image command when
installing the datastore-secret entrypoint. This ensures a fresh primary both
applies the PostgreSQL schema and starts the API instead of exiting cleanly
with no listener.

Primary preflight now rejects undersized artifact and API credentials before
containers start. Loop roles use process-liveness health checks and the signed
gateway checks its actual port, eliminating false unhealthy states inherited
from the control-plane image.

The operating topology is unchanged:

- genomesbox is the signed non-HA standalone primary;
- bigmac runs the two-wide PR-review worker, alarm dispatcher, and local
  fallback watchdog through the signed-leader gateway;
- bigmac never promotes the shared ledger and never automatically fails back;
- all seven runtime images remain immutable digest references.
