# Genomes Agentic OS 0.11.0

Version 0.11.0 adds host sentinel alerts and includes the validation-authority,
readiness, and Execution Fabric fixes merged since 0.10.1. Conventional Commit
history selects a minor release because it includes the host sentinel feature.

## Changes

- Host sentinel alerts report reboots and unreachable hosts and retain run
  evidence (#279).
- Validation and review evidence bind to the current source and policy. Native
  monitor ownership is preserved, and configured Python checks use a qualified,
  locked toolchain (#311; AGE-262).
- Tracker content determines Auto-Dev readiness (#268).
- Schedule dry-runs remain non-mutating. Runtime changes preserve bounded
  timeouts and worker sessions, separate readback credentials, and recover
  fenced delivery and transient leadership renewal failures (#280).
- The primary Execution Fabric restarts after reboot, with runnable backup
  recovery (#281).
- LOS security routes, private repository boundaries, and sibling test-path
  boundary collisions are repaired (#285, #283, #276).
- CI uses available MinIO dependency images (#282), and `@vitejs/plugin-react`
  is updated to 6.1.1 (#272).

## Release and installation

The release preparation changes only version records and release notes, keeping
Python, Node services, lockfiles, the chart, and the release manifest at 0.11.0.
It does not import changes from open pull requests.

The immutable `v0.11.0` tag and GitHub Release are published after the release
preparation merges to `main` and required checks pass. These notes describe the
intended release contents; they do not establish publication or installation.
