# Genomes Agentic OS 0.11.0

Version 0.11.0 carries the host sentinel feature and the delivery and runtime
repairs merged since 0.10.1. The release number follows the canonical
Conventional Commit derivation; publication remains pending the protected
release checks and immutable tag.

## Added

- An off-box host sentinel reports reboot and unreachable-host conditions,
  with registered run evidence and portable host naming
  ([#279](https://github.com/michaelwclark/genomes_agentic_os/pull/279)).

## Fixed

- Opposing-review admission follows frozen project policy. Explicit legacy
  policy binding preserves task history and review budgets. Unavailable
  evidence stays unavailable and must have valid source identity, provenance,
  scrub status, and coherent findings; unresolved findings still block
  ([AGE-220](https://linear.app/genomes/issue/AGE-220/honor-pinned-opposing-review-unavailable-policy-at-readiness),
  [#289](https://github.com/michaelwclark/genomes_agentic_os/pull/289)).
- Tracker content determines Auto-Dev readiness, and LOS security schedules
  use corrected task routes
  ([#268](https://github.com/michaelwclark/genomes_agentic_os/pull/268),
  [#285](https://github.com/michaelwclark/genomes_agentic_os/pull/285)).
- Schedule dry-runs stay non-mutating; bounded execution timeouts, worker
  sessions, and terminal-delivery retries survive the relevant fallback paths
  ([#280](https://github.com/michaelwclark/genomes_agentic_os/pull/280)).
- Primary and backup Execution Fabric workers recover after reboot; CI uses
  the reviewed replacement MinIO image sources
  ([#281](https://github.com/michaelwclark/genomes_agentic_os/pull/281),
  [#282](https://github.com/michaelwclark/genomes_agentic_os/pull/282)).
- Performance and configuration-migration gates correctly distinguish
  production filenames from tests, and repository visibility boundaries remain
  provider-neutral
  ([#276](https://github.com/michaelwclark/genomes_agentic_os/pull/276),
  [#283](https://github.com/michaelwclark/genomes_agentic_os/pull/283)).

## Release and installation

Python, service packages and lockfiles, the worker chart, and the release
manifest share version 0.11.0. Publication requires the exact merged revision's
checks and the new immutable `v0.11.0` tag. A merge or locally built wheel alone
does not establish publication or installed runtime acceptance.

Runtime replacement uses the guarded installer with verified wheel checksums,
a complete offline dependency lock, and drained review producers. Preserve
all existing review receipts and budgets through runtime and harness readback.
Legacy task policy binding is explicit and additive; it does not repair
deferred-to-CI predecessor bookkeeping or relax test and coverage gates.
