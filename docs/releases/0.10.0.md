# Genomes Agentic OS 0.10.0

Version 0.10.0 is the minor release that ships the governed dead-letter
replay CLI verb for Project Rubicon's fabric-health lane, alongside a
tracker-team fix and a regression-test pin.

## Added

- Add `agentic-os runtime dead-letter replay --task-id <uuid> --actor <actor>
  [--idempotency-key <key>] [--apply] [--json]`, the first local CLI path to
  the fabric's admin-authenticated `/api/v1/admin/tasks/:taskId/requeue`
  route. Dry-run by default; `--apply` requeues one failed, dead-lettered, or
  cancelled task with an idempotent operator receipt. This verb is what
  AGE-212 needed; AGE-212 itself remains in progress, with the incident's
  dead-letter drain still pending an operator admin token.
- Pin the AGE-214 acceptance shape for
  `_validate_team_pr_helper_receipt_wrapper` as a regression test after
  confirming no live defect against the real wrapper JSON for all 10 affected
  dead-lettered `pr_reviews` tasks.

## Fixed

- Move `genomes_agentic_os` Linear seeds from the Clarks Consulting/CC Linear
  team to the dedicated Agentic OS/AGE team so tracker workflow-state
  lookups resolve against the team that actually owns this project's issues
  (AGE-205).
