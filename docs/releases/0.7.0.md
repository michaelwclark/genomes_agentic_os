# Genomes Agentic OS 0.7.0

Version 0.7.0 makes Auto-Dev review execution bounded, idempotent, and safe to
resume across entrypoints and release upgrades.

## Review coordination

- One canonical full Review Self pass per base and policy chain.
- Same-key replay and concurrent kickoff reuse one immutable receipt before a
  reviewer or provider is called.
- Repair commits use descendant-only delta review, capped at three per chain.
- Finalize consumes exact-head review authority and never starts another
  review.
- A hard circuit breaker requires explicit operator approval plus exact-head
  local and hosted evidence after the cap; it cannot post reviewer approval.
- Provider publication is clean-only, readback-verified, and capped at one
  consolidated terminal summary.

## Runtime rollout

The local installer verifies wheel and dependency hashes, evaluates dependency
markers with the target interpreter, drains active review families, preserves
the byte-identical receipt-ledger union, holds family locks through activation,
and maintains verified previous-release rollback pointers.

## Deployment requirement

Stop old and new review producers, migrate the review ledger into the shared
root, create the revision-bound rollout proof documented in
`docs/45-auto-dev-review-coordination.md`, then install the exact release wheel.
Resume review traffic only after the runtime, harness projection, coordination
root, package version, and rollback aliases all pass readback.
