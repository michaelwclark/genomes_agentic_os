# Genomes Agentic OS 0.5.7

Version 0.5.7 makes the repaired execution-fabric control-plane behavior and
the governed release contract available from one reviewed source revision.

## Included

- Execution-fabric repair roles verify active promoted-role health and retain
  convergence, recovery, and failure visibility.
- The Agentic OS release adapter uses the reusable additive-only contract,
  preserves immutable tag and asset identity, and reads back every asset name,
  byte size, and SHA-256 digest.
- The canonical release policy documents the installed Agentic OS adapter and
  the planned adoption modes for the Harness, Library, and Brain roles.

## Validation

The release-preparation commit must pass all protected repository checks. The
tag-triggered release then independently verifies main ancestry, twelve version
mirrors, the eight-asset manifest, and the newly built immutable
execution-fabric image digests before completion.
