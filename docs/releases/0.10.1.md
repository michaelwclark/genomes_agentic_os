# Genomes Agentic OS 0.10.1

Version 0.10.1 is the patch release that closes a runtime contract-gate
test-path collision, an opportunistic Execution Fabric spare-slot claim
regression, and a supervisor queue-dispatch budget bug, and backfills the
missing 0.9.0 release notes.

## Fixed

- The runtime contract gate's `TEST_PATH` separator boundary no longer lets
  production modules named like `testimonial.py` or `testing_utils.py`
  prefix-match the test-file exemption and silently bypass runtime-risk
  classification; the redundant second `test_*.py` alternation is removed as
  already covered by the boundary form (AGE-213).
- Execution Fabric keeps an active attempt alive when an opportunistic
  spare-slot claim hits a transport timeout, instead of exiting and letting
  the active lease expire. API fencing and claim failures on an idle worker
  still fail closed; only genuine transport failures
  (`ExecutionFabricTransportError`) are treated as non-terminal.
- `runtime supervise --apply` dispatches queued work through the governed
  long-run monitor and returns a run ID and artifact directory without
  waiting for the task to finish, so a legitimately long queue item no
  longer starves later schedule ticks under a hardcoded wait. Dry-run
  previews stay synchronous and deterministic.

## Release and installation

This PR projects Agentic OS and all Execution Fabric release surfaces to
0.10.1, keeping one coherent Python, Node, chart, manifest, and lockfile
version. The `v0.10.1` tag and GitHub Release are cut only after this PR
merges to `main` and its required checks pass — this document describes
what that tag will carry, not a completed publication.
