# Genomes Agentic OS 0.6.2

Version 0.6.2 is a patch release for the Team PR Sync incident repair.

## Fixed

- Accept the current Team PR review helper wrapper, where successful execution
  and the review outcome are distinct fields, while retaining the documented
  legacy outcome-in-status form.
- Reject empty, mismatched, or otherwise malformed wrapper outcomes before
  they can project a review result.
- Keep Fabric notification dispatch on its immutable worker Python runtime.

## Rollout requirement

Install the exact released artifact on the controller and BigMac Fabric worker,
then run the page-scoped Team PR canary before re-enabling the scheduler.
