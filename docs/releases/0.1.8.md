# Genomes Agentic OS 0.1.8

Version 0.1.8 introduces a single canonical work-item layout and a complete
maintainer Auto-Dev delivery profile.

## Highlights

- New work is stored as a date-prefixed packet directly under `work-items/`.
- Terminal packets can be retained for a configurable number of days, weeks,
  or months before Work Item Archive Health moves them to `99-archived/`.
- Auto-Dev and routing surfaces search retained archive history when a ticket
  returns.
- The Genomes Agentic OS maintainer profile now covers the full 16-stage
  lifecycle from Linear grooming through QA, gated merge, release, and docs.
- The installer QA contract proves a fresh install and repeated installation
  over an existing secondary instance while preserving operator-owned files.

## Validation

- Repository test suite: 1,406 passed.
- GitHub Actions `pytest`: passed for the merged feature revision.
- Fresh install, secondary install, and secondary reinstall: passed with the
  operator sentinel preserved.

## Compatibility

Existing `01-intake`, `02-active`, and `03-complete` folders remain readable as
legacy import surfaces. New work is never routed into those folders.
