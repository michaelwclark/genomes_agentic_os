# Release 0.11.2

Published MinIO smoke tests could complete amd64 checks and fail when Docker
selected the arm64 image, preventing the complete release from being published.
Every published server and client operation now uses the verified child digest
for its requested architecture. Receipts retain the signed parent index and
record the executed child; publication and release-asset verification reject a
mismatched child, architecture or parent.

The Linux PR lane includes a sequential amd64 then arm64 regression in one Docker
store using immutable published images. The complete release publisher still
requires the actual storage, health, secret-file, persistence and cleanup checks
before publishing SDK and Execution Fabric assets.

The focused source-contract suite passed 104 tests. Hosted PR checks and the new
version's complete publisher provide the remaining release evidence.
