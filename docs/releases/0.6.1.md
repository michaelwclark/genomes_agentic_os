# Genomes Agentic OS 0.6.1

Version 0.6.1 is a patch release for governed Auto-Dev delivery and
execution-fabric recovery. It aligns the Python, Node, lockfile, Helm, and
release-manifest version sources at `0.6.1`.

## Upgrade notes

- Align all twelve canonical Python, Node, lockfile, Helm, and release-manifest
  version sources at `0.6.1`.
- This patch release contains governed delivery-packet recovery, queue
  isolation, source-branch refresh, policy routing, and idempotent policy
  migration/admission handling. The Team PR effect-key route and paired
  object-library producer ordering were already released in 0.6.0; no producer
  rollout or queue quiescence is required for a 0.6.0 → 0.6.1 upgrade.
- For operators upgrading from 0.5.x, follow the 0.6.0 ordering rule: ship the
  Agentic OS route before the paired producer and quiesce the review queue until
  legacy effect-key work is drained or reconciled.
- Release and deployment operators must use the reviewed release commit and
  preserve the host-pinned durability requirement for Team PR state.

The corresponding release tag and GitHub Release must be created only from
the reviewed `main` release commit after exact-head checks and required review
gates are green.
