# Genomes Agentic OS 0.6.1

Version 0.6.1 is a patch release for governed Auto-Dev delivery and
execution-fabric recovery. It aligns the Python, Node, lockfile, Helm, and
release-manifest version sources at `0.6.1`.

## Upgrade notes

- Apply the Agentic OS route before updating the paired object-library
  producer. If the producer is upgraded first, stop it, restore the route,
  drain or reconcile queued intents, and then retry the producer upgrade.
- **All upgrades:** pause Team PR review workers and admit no new jobs while
  the route and producer are upgraded. Keep the queue quiesced until queued
  intents are drained or reconciled. Do not relax this gate unless the running
  route's persisted first-format guard has been independently verified.
- Do not downgrade to `0.6.0` while full-intent work is queued. Drain or
  reconcile the queue first, then restore the prior route and producer together.
- Release and deployment operators must use the reviewed release commit and
  preserve the host-pinned durability requirement for Team PR state.

The corresponding release tag and GitHub Release must be created only from
the reviewed `main` release commit after exact-head checks and required review
gates are green.
