# Genomes Agentic OS 0.6.1

Version 0.6.1 is a patch release for governed Auto-Dev delivery and
execution-fabric recovery. It aligns the Python, Node, lockfile, Helm, and
release-manifest version sources at `0.6.1`.

## Upgrade notes

- Apply the Agentic OS 0.6.1 route before updating the paired object-library
  producer. If the producer is upgraded first, stop it, apply the 0.6.1 route,
  drain or reconcile queued intents, and then retry the producer upgrade.
- **Paired producer transition:** when advancing the object-library producer
  across the `review_mode` boundary, pause Team PR review workers and admit no
  new jobs. Keep the queue quiesced until queued intents are drained or
  reconciled. The route and paired producer are separate deployables; advance
  them in the documented order.
- For a paired producer transition, downgrade in this order: pause review
  workers and stop admitting new review jobs; stop the current producer; drain
  or reconcile queued intents; confirm no `review_mode`-bearing intents remain
  in flight; roll the route back to `0.6.0`; then restore the prior producer.
- Release and deployment operators must use the reviewed release commit and
  preserve the host-pinned durability requirement for Team PR state.

The corresponding release tag and GitHub Release must be created only from
the reviewed `main` release commit after exact-head checks and required review
gates are green.
