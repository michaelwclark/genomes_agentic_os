# Genomes Agentic OS 0.8.0

Version 0.8.0 adds the governed production-release validation stage and lands
a batch of Auto-Dev delivery and release-runtime repairs from one merge
train.

## Added

- A governed pre-merge production-release validation stage, with its own
  policy and command registrations and workflow registry objects, that fails
  closed on incomplete release-family, exact-head QA, configuration,
  performance, runtime-consumer, security, compatibility, rollback, and
  observability evidence, plus the durable run-log storage that backs it.

## Fixed

- Recover the exact former unbound Everything delivery boundary through an
  explicit, dry-run-first bootstrap that validates task, portfolio,
  projection, policy, canonical-work, and receipt preconditions before
  backfilling only the missing boundary fields, preserving immutable
  provenance and RunLogStore state.
- Restart loaded macOS Execution Fabric launchd labels only after a complete
  preflight, and replace the in-memory prior worker once the current-release
  symlink changes.
- Align Commitizen's package, hook, lockfile, and enforcement contract at
  version 4.17.1.

## Included pull requests

- #194 — governed production-release validation stage and run-log storage.
- #227 — legacy unbound Everything delivery boundary recovered.
- #245 — macOS Execution Fabric activation restart (restack of #229).
- #244 — Commitizen contract completed (successor to #223).

## Release and installation

PR #250 authorized this version increment after the 2026-08-17 merge train;
QA was explicitly deferred by the operator. The release commit left the
Python runtime mirror, Python lock, static release manifest, Node
package/lock mirrors, and worker chart out of sync with each other, which
broke locked CI and release-contract validation on `main`. No GitHub Release
was published for this tag. Because `v0.8.0` is immutable it could not be
corrected in place; install [0.8.1](0.8.1.md) or later instead.
