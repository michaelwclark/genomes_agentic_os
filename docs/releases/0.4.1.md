# Genomes Agentic OS 0.4.1

This patch release completes the first unified Execution Fabric release.

## Corrections

- Preserve strict `not_required` Auto-Dev stage receipts when a surrounding
  work item has a reviewed subject revision.
- Build `SHA256SUMS` from published assets only; checksum staging now occurs
  outside the release asset directory.
- Keep the Python package, runtime, Node services, Helm chart, and release
  manifest on one canonical `0.4.1` version.

## Upgrade

Use the digest-pinned images and portable bundles published with the GitHub
release. Do not deploy a two-host active/passive topology until an independent
leadership-witness account is configured and the documented failover drills
pass.
