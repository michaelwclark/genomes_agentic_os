# Genomes Agentic OS 0.5.1

Version 0.5.1 is the installable personal-primary release. It contains the
complete v0.5.0 Execution Fabric feature set and repairs the leadership-witness
multi-architecture build so dependency installation runs only on BuildKit's
native build platform.

The v0.5.0 tag is retained as the immutable receipt for an unpublished failed
release. Its witness image could not be assembled for ARM64 because npm was
executed through QEMU and terminated with `SIGILL`; no GitHub v0.5.0 release
was created. Install and deploy v0.5.1 instead.

All safety boundaries from the 0.5.0 release notes remain unchanged:

- genomesbox is the signed, non-HA standalone primary;
- bigmac runs the two-wide PR-review worker, alarm dispatcher, and local
  fallback watchdog through the signed-leader gateway;
- bigmac never promotes the shared ledger and recovery never auto-fails back;
- all seven runtime images remain immutable digest references.
