# Genomes Agentic OS 0.11.1

Version 0.11.1 repairs release publication after the configured upstream MinIO
container repositories became unavailable to the publisher. Conventional Commit
history selects a patch release after the immutable 0.11.0 tag.

## Changes

- Build owned MinIO server and client images from the same configured official
  versions: server RELEASE.2025-09-07T16-13-09Z and client
  RELEASE.2025-08-13T08-35-41Z.
- Verify official payload checksums and Minisign signatures, pin the runtime
  base, and bind immutable image indexes, platform children and provenance to
  the exact source and input records.
- Require actual amd64 and arm64 checks for binary identity, health, object
  writes and reads, persistent data, secret-file startup and fixture cleanup.
- Keep the complete release contract: the image lock, manifest, SBOM, configuration
  and emergency bundles, SDK wheel and source archive, and SHA256SUMS.

## Release and installation

Python, Node services, lockfiles, the chart and release manifest are prepared at
0.11.1. The original 0.11.0 tag and its failed publisher remain historical
evidence. The new v0.11.1 tag and complete GitHub Release are published after
the reviewed source merges to main and required checks pass.

These notes describe the intended release contents. Publication and installation
require separate provider and installed-package verification.
