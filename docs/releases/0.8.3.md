# Genomes Agentic OS 0.8.3

Version 0.8.3 is the patch release that closes three runtime and contract-gate
defects found during the 2026-08-26 stabilization pass and tightens Review
Self's repository selection.

## Fixed

- Runtime status no longer crashes. It now routes through the same
  normalizing snapshot projection as runtime snapshot, so a remote or
  remote_with_local_fallback transport does not raise `KeyError: 'health'`;
  an absent health/worker_pools/filters section renders as unknown/absent
  instead (AGE-211).
- The runtime contract gate now catches direct Python runtime modules (for
  example `views.py`) that a double-escaped regex previously let bypass it,
  and no longer over-matches unrelated files (`apiary.py`, `ruler.py`,
  `serviceability.py`, `requester.py`) whose names merely contain a contract
  keyword (AGE-205).
- Installed roots heal stale `harness/bin` executables on the next governed
  docs update instead of permanently keeping whichever binary their first
  projection wrote, unblocking strict policy-context resolution for
  shared-factory projects (AGE-200).
- Review Self now requires an unambiguous, canonical-config-derived
  repository selection and fails closed with a typed pre-admission receipt
  before invoking an external reviewer (#256).
- Review Self accepts the initial opposing-model request for shared-factory
  PR packets, discovered under both domain projects and
  `harness/shared_factory` (#257).
