# Genomes Agentic OS 0.4.0

Version 0.4.0 makes the Execution Fabric a portable, observable runtime for
named queues and host-native workers without changing the default installed
queue mode.

## Highlights

- PostgreSQL is the durable task, attempt, run, event, effect, alarm, finding,
  repair, and artifact ledger; BullMQ/Valkey is a reconstructable delivery
  plane.
- Worker pools have explicit queue, capability, concurrency, lease, retry,
  backpressure, and dead-letter policy in one canonical instance config.
- genomesbox and bigmac use a witness-fenced leadership epoch. Promotion is
  automatic only when explicitly enabled; failback remains manual.
- Run reports are uploaded through task-attempt-scoped short-lived URLs.
  Stored bytes are SHA-256 verified and visible from task detail and artifact
  snapshots.
- Failed report uploads survive pod replacement in an RWX spool. Recovery is
  bound to the durable worker plus the assignment's opaque recovery token;
  corrupt or exhausted entries are quarantined and their health is visible
  centrally.
- MinIO replication is active-active with one witness-selected writer.
  Timed canaries prove both directions, and stale artifact-RPO receipts fence
  promotion and failback.
- Command Center shows queue depth, capacity, workers, runs, effects, alarms,
  healing, configuration drift, leadership, and failover state.
- The Kubernetes chart is a generic one-credential GAOS worker. It validates
  shipped handlers before registration and does not pretend to include LOSMON
  environment or Jira handlers.

## Release and installation

The release publishes the Python wheel and source distribution, digest-pinned
control-plane and witness images, release manifest, image lock, checksums,
SBOM, config/schema bundle, and emergency bundle. The wheel contains a small
resource index that points operators to these version-matched assets and the
complete scaffold runtime needed for a fresh `init`. CI proves the direct and
source-distribution-derived wheel resource inventories are identical, then
installs the latter into an empty environment and tests init, validation, and
receipt-backed external-library reinstall. Deployment trees are not copied
into the installed Agentic OS root.

Availability in source or a release does not activate the managed queue.
Operators must provision protected secrets and Tailscale routes, deploy both
data sites plus the independent witness, reconcile artifact replication, pass
the failover/failback drill, and explicitly apply the queue-mode change.

## Compatibility

Filesystem queue mode remains the default and rollback target. Managed
producers use exactly one selected writer; no silent dual-write or implicit
in-flight migration is introduced.
