# Genomes Agentic OS 0.6.3

Version 0.6.3 repairs release activation for the Team PR Sync incident.

## Fixed

- macOS Execution Fabric activation now restarts already loaded Fabric service
  labels after preflight. This guarantees that the BigMac worker imports the
  exact newly activated package rather than retaining the previous release in
  memory.

## Rollout requirement

Keep the Team PR scheduler disabled during activation. Verify the restarted
worker imports this release, then run only the approved page-scoped canary and
require the Fabric, Notion, GitHub, Slack, Team PR Runs, and notification
readbacks before re-enabling the scheduler.
