# Genomes Agentic OS 0.9.0

Version 0.9.0 is the minor release that ships the governed FullSail updater
Execution Fabric route for Project Rubicon's VPN-aware NFCU-to-FullSail
controller.

## Added

- Add the closed `los.fullsail_updater.job.v1` Execution Fabric route, its
  single-wide `los_fullsail` queue and worker pool, and bigmac host affinity
  so the VPN-aware NFCU-to-FullSail controller can execute without admitting
  arbitrary commands. The route admits only `job_id` and `job_kind`; the
  worker invokes the installed controller, which independently validates
  dependency state, the exact VPN route, and manifest approval before any
  target mutation.
- Add the installed FullSail updater command adapter and a governed
  four-hour local notification policy for pending VPN or manifest-approval
  action, so a stalled route produces rate-limited operator attention
  instead of a retry storm.

## Release and installation

Unlike 0.8.2, 0.8.3, and 0.10.0, no separate release-prep PR authored this
version: feature PR #263 carried the coherent Python, Node, chart, manifest,
and lockfile version bump to 0.9.0 in the same squash commit
(`7b111f59b54b45286c49f2ca2eeeab4c887ad1d7`), merged and tagged `v0.9.0` on
2026-08-26. A GitHub Release was published for `v0.9.0` on 2026-08-26,
carrying the Python wheel and source distribution, the Execution Fabric
config/schema bundle, emergency bundle, image lock, release manifest, SBOM,
and a `SHA256SUMS` checksum file — the same asset set as prior tagged
releases.
