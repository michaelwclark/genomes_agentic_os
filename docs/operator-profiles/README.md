# Operator email voice profiles

Operator-owned style profiles are opt-in instance data. Michael Clark authorized publishing his derived profile here; raw messages and recipient details are excluded.

To use his profile in his own installation, copy michael-clark/EMAIL_VOICE.md to <os-root>/harness/config/EMAIL_VOICE.md. Do not install it as a customer or another employee voice default. Current author instructions override historical style evidence. No automatic extraction, external mail access, model training or send authorization follows from installation.
