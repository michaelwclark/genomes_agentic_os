# Example Domain: Personal

Personal work covers household operations, planning, learning, reminders, administrative tasks, and the user's own non-client projects.

## Suggested Lanes

- `personal_admin`
- `learning`
- `operations`

## First Workflows

| Workflow | Purpose |
| --- | --- |
| `inbox_triage` | Turn raw notes, reminders, and loose prompts into routed work. |
| `weekly_plan` | Review active work and create a realistic weekly plan. |
| `learning_capture` | Preserve useful notes, links, and decisions from research or classes. |

## First Automations

| Automation | Level | Purpose |
| --- | --- | --- |
| `daily_brief_prepare` | `prepare` | Draft a daily brief from calendar, open work, and reminders. |
| `follow_up_scan` | `observe` | Identify stale waiting items that need a human decision. |

## Approval Bias

Personal automations can often move faster, but external sends, purchases, account changes, and destructive cleanup still require explicit approval.
