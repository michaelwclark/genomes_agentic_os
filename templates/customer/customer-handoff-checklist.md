# Customer Handoff Checklist: <customer_or_project>

## Operating Surface

- [ ] OS root installed or updated.
- [ ] Rooms/domains match the customer's language.
- [ ] Root router points to room routers.
- [ ] Room `CONTEXT.md` files include read-first, read-when-needed, skip, tools, and done criteria.
- [ ] Source map lists real systems and owners.

## Workflow And Automation Assets

- [ ] Workflow map is documented.
- [ ] Automation candidates are scored.
- [ ] Approval gates are explicit.
- [ ] Run logs exist for pilot runs.
- [ ] Failure modes are documented.
- [ ] Rollback or recovery path is documented.

## Control Plane

- [ ] Notion or approved control plane is verified.
- [ ] Work queue exists.
- [ ] Runs or activity log exists.
- [ ] Approval queue exists for risky actions.
- [ ] Current plan or dashboard has a stable home.

## Security And Data

- [ ] Credentials are scoped and documented.
- [ ] Prohibited systems are listed.
- [ ] Retention and deletion notes are captured.
- [ ] Customer-visible outputs require approval.

## Training

- [ ] Operator knows where to start work.
- [ ] Operator knows how to approve or reject outputs.
- [ ] Operator knows how to inspect a failed run.
- [ ] Next three automation candidates are captured.
