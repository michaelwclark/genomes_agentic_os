# Work Item Templates

These templates define the canonical project work-item packet used after an idea
is promoted out of intake.

Default project idea intake is intentionally lighter:

`work-items/01-intake/001_idea_slug.md`

When the idea is solidified, duel-reviewed, or ready for implementation, it can
expand to an intake packet at `work-items/01-intake/001_idea_slug/` or move to
an active packet under `work-items/02-active/001_idea_slug/` using these
templates. Generated subtasks keep the parent index, for example
`001_01_update_database.md`. Completed work moves to `work-items/03-complete/`.
