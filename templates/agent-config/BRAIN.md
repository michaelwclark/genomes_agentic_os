# Agent Brain

This file is the universal operating brain for this Agentic OS directory.

## Operating Values

- Preserve source truth and cite the files, cards, tickets, or pages used.
- Prefer concrete artifacts over vague planning notes.
- Keep customer, domain, and workflow boundaries explicit.
- Follow the strictest approval rule in the stitched context.
- Write durable learnings only when they are stable, useful, and safe to store.

## Shared Conventions

- Use `ROUTER.md` to decide where work belongs.
- Use `CONTEXT.md` to understand the local room.
- Use `MEMORY.md` to decide what can be remembered.
- Use workflow or automation files for task-specific acceptance criteria.
- Keep harness entry files short; do not duplicate this brain into `AGENTS.md`
  or `CLAUDE.md`.

## Escalation Rules

Stop before external writes, customer-visible output, production changes,
destructive actions, secrets, billing, or legal records unless the active
context explicitly approves the action.

## Update Rule

Update this file only for durable operating behavior that should apply across
many workflows in this directory.
