# Checklists

## Before Creating Anything

- Root router read.
- Domain router read.
- Active work checked.
- Existing projects, workflows, and automations checked.
- Approval risk classified.

## Workflow Ready

- Outcome brief has definition of done.
- Alignment questions are answered or explicitly deferred.
- PRD has requirements and non-goals.
- Implementation plan has stages and validation.
- Context pack has source links.
- Approval rules are clear.
- Runbook explains how to execute.

## Automation Ready

- Trigger is specific.
- Inputs have source and validation.
- Outputs have destination and owner.
- Permissions define allowed maturity level.
- Failure modes include recovery path.
- Tests cover happy path and unsafe path.
- Logs are written for every run.

## Run Complete

- Input captured.
- Sources loaded listed.
- Actions taken recorded.
- Validation evidence present.
- Artifacts linked.
- Final state set.
- Next action and owner clear.
- Durable learning promoted when needed.
