# Layer Map

Use the narrowest layer that can hold the work without hiding context.

| Layer | Use For | Do Not Use For |
| --- | --- | --- |
| Root | Routing to domains. | Active work, client notes, task status. |
| Domain | Standing context, policy, source systems, active work. | Reusable cross-domain templates. |
| Project | Outcome-specific plans, links, decisions, artifacts. | Global domain rules. |
| Workflow | Repeatable process with judgment, context, approvals, and validation. | Trigger schedule or unattended execution. |
| Automation | Stable trigger-driven work with permissions and tests. | Ambiguous judgment. |
| Run | Evidence of one execution. | Long-term policy unless promoted. |
| Shared factory | Templates, examples, skills, commands, diagrams, and schemas. | Live client state. |
