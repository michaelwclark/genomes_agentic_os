# Troubleshooting

## I Do Not Know Where This Goes

Read root `ROUTER.md`, then the likely domain `ROUTER.md`. If still unclear, capture the item in `<domain>/01-inbox/triage.md` with risk and confidence.

## The Root Is Getting Crowded

Move active work into a domain. Root should contain the router, compatibility pointers, README, and domain folders.

## A Workflow Feels Too Big

Split by outcome or phase. Keep one workflow focused enough that a run log can prove whether it worked.

## An Automation Feels Risky

Keep it at `observe` or `prepare`. Do not allow execution until permissions, tests, rollback, and approval rules are written.

## Agents Keep Missing Context

Update `CONTEXT.md`, `REFERENCES.md`, project `source-map.md`, and workflow `context-pack.md`. Do not rely on a chat transcript as the only memory.

## The OS Feels Like Static Docs

Create run logs. A running OS has visible execution records, status changes, routing updates, and promoted learnings.
